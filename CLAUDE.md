
# NetPulse Project Instructions

## Project Goal
Build a network performance monitoring system for Networking 2.

## Planned Stack
- Python for network monitoring logic
- Flask for the web backend
- HTML, CSS, and JavaScript for the frontend
- Chart.js for visualizations
- Supabase for the database later

## Development Workflow
- Teach one concept at a time.
- Give me one task at a time and wait for me to finish.
- Explain what the code does and why it is needed.
- Let me write the code myself.
- Do not implement the entire project or generate large amounts of code without permission.
- Review my work and guide me through debugging.
- Explain proposed file changes before making them.

## Safety
- Do not run network tests without asking me first.
- Only test systems I own or have explicit permission to test.
- Do not perform vulnerability scans without authorization.
- Do not install dependencies or modify system settings without asking first.
- Do not configure the database until I explicitly request it.
